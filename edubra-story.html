How it works

1Send a fileA .txt, .docx or .pdf goes into a small web page.

2Over Wi-FiThe text, split into words, travels to the Raspberry Pi.

3Audio firstThe Pi makes one audio file per word before it starts.

4ReadIt speaks each word, then raises the pins letter by letter.
