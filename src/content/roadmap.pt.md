# Agente H

## Painel

> O painel do dono para operar o agente.

- **Painel** — catálogo, conversas, leads, instruções e horário de funcionamento. *Feito*
- **Usabilidade** — deixar o painel mais fácil de usar. *Próximo, Fev 2027*

## Inteligência de vendas

> Como o agente encontra produtos e identifica compradores prontos.

- **Busca no catálogo** — busca por significado com pgvector. *Feito*
- **Qualificação de leads** — classifica cada conversa e entrega ao dono os compradores prontos. *Feito*

## Integrações

> Conexão com o WhatsApp, o estoque da loja e os fluxos do n8n.

- **API Cloud do WhatsApp** — conectar o Agente H à API oficial do WhatsApp da Meta para enviar e receber mensagens. *Próximo, Dez 2026*
- **Sistemas de estoque** — aprender como funcionam os sistemas de estoque das lojas, para manter o catálogo atualizado automaticamente. *Próximo, Dez 2026*
- **Fluxos do n8n** — atualizar os fluxos para a nova versão: API da Meta, banco de dados e sincronização do catálogo. *Próximo, Jan 2027*

# RP3

## Algoritmo do ângulo de preenchimento (programação dinâmica)

> Um método de programação dinâmica para escolher o ângulo de preenchimento de cada camada.

- **Implementação** — um algoritmo de programação dinâmica que escolhe o melhor ângulo de preenchimento para cada camada com 100% de preenchimento, dada uma margem acrescentada por camada. *Fazendo, meta Nov 2026*
- **Testes** — rodar o algoritmo em diferentes modelos e margens. *Próximo, Dez 2026*
- **Análise dos resultados** — analisar e documentar os resultados. *Próximo, Dez 2026*
